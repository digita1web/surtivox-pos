# Guía rápida de uso

## Icono
Usa `brand/app-icon.svg` como fuente vectorial editable. `brand/app-icon-1024.png` es una exportación raster de 1024×1024 cuando la conversión SVG estuvo disponible. El diseño incluido es una primera propuesta conceptual, no un logo registrado ni una validación legal de marca.

## Iconos UI
Los SVG de `icons/` usan `currentColor`, por lo que el color se define desde la aplicación. Recomendación: 24×24 dp, trazo de 1.8 px, sin rellenos grandes, salvo puntos del icono “Más”. Aplicar el verde `#19B88E` al elemento activo y `#929BA9` a elementos inactivos.

## Accesibilidad y contraste
- Texto principal: `#F1F3F6`.
- Texto secundario: `#929BA9`; no usarlo para texto diminuto sobre fondos con poco contraste sin comprobarlo.
- No comunicar errores solo con rojo; acompañar con texto o icono.
- Para el botón principal verde, comprobar contraste de texto oscuro/blanco en tamaños reales. La elección depende del tamaño y peso tipográfico.

## Splash
El prompt genera una dirección visual; la ilustración final no está incluida porque debe generarse aparte. Mantén el área central libre si vas a superponer el logo desde código.

## Licencias
Los SVG y documentos de este kit se han creado como recursos iniciales para este proyecto. Comprueba las licencias de cualquier fuente, icono o imagen externa que añadas después.
