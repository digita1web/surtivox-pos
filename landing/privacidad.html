Privacidad

Cómo funciona la landing, qué datos intervienen al descargar la app y dónde se guarda la información de tu tienda.

Última actualización: 29 de octubre de 2026.

1. Alcance de esta política

Esta política aplica al sitio publicado en GitHub Pages y a la información básica sobre el funcionamiento de Surtivox POS. No crea cuentas ni recopila datos personales mediante formularios en esta landing.

2. Datos de la landing

La landing no incluye formularios de registro, pagos, comentarios ni analítica propia. Tampoco utiliza cookies publicitarias ni perfiles de usuario.

Para mostrar la versión y el peso del APK, el navegador consulta la API pública de GitHub. Esa solicitud puede transmitir a GitHub tu dirección IP y datos técnicos de la conexión, sujetos a la política de privacidad de GitHub. La landing no recibe ni almacena esos datos.

El sitio se aloja en GitHub Pages. GitHub puede registrar información técnica y de acceso conforme a sus propias políticas.

3. Almacenamiento técnico

La landing usa el almacenamiento de sesión del navegador para guardar durante un máximo de 15 minutos la versión y el tamaño del release consultado. Esta información es técnica, permanece en tu dispositivo y se elimina al cerrar la sesión del navegador.

4. Datos de la aplicación

Surtivox POS guarda productos, ventas, clientes, fiados y reportes en una base de datos SQLite dentro del teléfono. La landing no accede a esa base de datos.

El respaldo en la nube es opcional. Si el usuario lo activa, los datos se procesan mediante el Worker y los servicios de infraestructura configurados para Surtivox, bajo las condiciones que se informen dentro de la app. El usuario puede no activar ese respaldo y seguir usando las funciones locales.

La consulta de precios de referencia envía un EAN a un servicio de Surtivox que consulta catálogos públicos de supermercados. No se envían nombres de clientes, ventas ni datos de fiado en esa consulta.

5. Datos de terceros

Los enlaces a GitHub, las descargas desde GitHub Releases y las publicaciones de supermercados llevan a servicios de terceros. Sus políticas de privacidad y cookies son independientes de Surtivox. Revisa esas políticas antes de usar esos servicios.

6. Seguridad

Se aplican medidas razonables para mantener el sitio y la app disponibles, pero ningún sistema es completamente infalible. El usuario es responsable de proteger su teléfono, su PIN, sus copias de seguridad y el acceso a su tienda.

7. Derechos y contacto

Puedes solicitar información, corrección o eliminación de datos personales que hayas compartido voluntariamente con el proyecto escribiendo en el repositorio oficial. Para datos almacenados únicamente en tu teléfono, puedes eliminarlos desde la app o borrando sus datos locales.

Canal de contacto: github.com/digita1web/surtivox-pos/issues.

8. Cambios

Esta política puede actualizarse cuando cambien la landing, la app o los servicios utilizados. La fecha de la última actualización aparece al inicio de esta página.

Nota: esta política describe el funcionamiento actual del proyecto y es una base estándar. Antes de operar un servicio comercial con cuentas, pagos o datos de terceros a escala, conviene revisarla con un especialista en protección de datos en Colombia.
